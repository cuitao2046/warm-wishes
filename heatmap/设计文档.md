# 本地图片查看器 - 设计文档

## 1. 系统架构

### 1.1 技术栈
- **HTML5**: 页面结构和语义化标签
- **CSS3**: 样式、变换、过渡动画
- **Vanilla JavaScript**: 无依赖的纯 JavaScript 实现
- **FileReader API**: 读取本地图片文件
- **Canvas API**: 绘制六边形网格

### 1.2 文件结构

image-viewer.html          # 单文件应用（包含所有 HTML、CSS、JavaScript）

## 3. 核心功能设计

### 3.1 图片上传模块

#### 数据流
```
用户操作 → fileInput change/drop
    → FileReader.readAsDataURL()
    → handleFiles()
    → loadedFiles.push(fileData)
    → showPreview(index)
```

#### 数据结构
```javascript
loadedFiles: Array<{
    name: string,        // 文件名
    size: number,        // 文件大小（字节）
    dataUrl: string      // Base64 编码的图片数据
}>

currentIndex: number          // 当前显示的图片索引
```

### 3.2 缩放模块

#### 状态变量
```javascript
currentZoom: number          // 当前缩放倍率 (0.1 ~ 10.0)
zoomStep: number = 0.25     // 缩放步长
minZoom: number = 0.1       // 最小缩放
maxZoom: number = 10.0      // 最大缩放
```

#### 实现方式
- 使用 CSS `transform: scale()` 实现缩放
- 使用 `transform-origin: 0 0` 设置缩放原点
- 添加 `transition: transform 0.1s ease-out` 平滑过渡
- 所有变换在同一 `applyTransform()` 函数中应用，确保图片和网格同步

### 3.3 拖拽模块

#### 状态变量
```javascript
isDragging: boolean          // 是否正在拖拽

startY: number              // 拖拽起始 Y 坐标
panX: number               // X 轴向偏移
panY: number               // Y 轴向偏移
```

#### 实现方式
- 事件：`mousedown` (imageWrapper), `mousemove` (document), `mouseup` (document)
- 只允许左键拖拽（`e.button === 0`）
- 只在缩放 > 1 时允许拖拽
- 使用 CSS `transform: translate()` 实现位移

### 3.4 六边形网格模块

#### 状态变量
```javascript
gridEnabled: boolean         // 网格是否显示
hexSize: number = 120       // 六边形半径（像素）
selectedGridIds: Set<string> // 当前选中的网格ID集合（多选）
isSelecting: boolean         // 是否正在框选
selectionStartX: number      // 框选起始X坐标
selectionStartY: number      // 框选起始Y坐标
selectionEndX: number        // 框选结束X坐标
selectionEndY: number        // 框选结束Y坐标
```

#### 实现方式
- 使用 `<canvas>` 元素作为覆盖层
- Canvas 尺寸使用图片的显示尺寸
- 六边形绘制逻辑：
  - 水平间距：`r * √3`
  - 垂直间距：`r * 1.5`
  - 奇数行向右偏移水平间距的一半
  - 六边形顶点角度从 `-π/6` 开始（30 度，尖顶朝上）

### 3.5 网格选中高亮模块

#### 状态变量
```javascript
selectedGridIds: Set<string> // 当前选中的网格ID集合（多选）
isSelecting: boolean         // 是否正在框选
selectionStartX: number      // 框选起始X坐标
selectionStartY: number      // 框选起始Y坐标
selectionEndX: number        // 框选结束X坐标
selectionEndY: number        // 框选结束Y坐标
```

#### 实现方式
- 使用 `pointer-events: auto` 让 Canvas 可以接收鼠标事件
- 网格层鼠标样式设置为 `crosshair`（十字准星）
- 六边形碰撞检测算法：
  - 首先使用矩形快速排除
  - 然后使用六边形几何公式精确判断
- 高亮绘制：
  - 普通网格：半透明绿色边框，线宽 1px
  - 选中网格：绿色半透明填充 + 不透明绿色边框，线宽 2px
- 切换选中：点击同一网格取消选中，点击不同网格切换选中
- 多选模式：
  - 直接点击/框选：替换选中
  - Ctrl/Cmd + 点击/框选：追加选中
  - 支持同时选中多个网格

#### 六边形碰撞检测算法
```javascript
function isPointInHexagon(px, py, centerX, centerY, size) {
    const dx = Math.abs(px - centerX);
    const dy = Math.abs(py - centerY);
    const size3_2 = size * Math.sqrt(3) / 2;

    // 快速排除：超出矩形范围
    if (dx > size || dy > size3_2) return false;

    // 六边形内部判断
    return (size3_2 * dx + size * dy / 2) <= size * size3_2;
}
```

#### 网格与矩形相交检测（AABB）
```javascript
function isGridInRectangle(grid, rectLeft, rectTop, rectRight, rectBottom) {
    // 使用六边形外接矩形进行AABB检测
    const hexLeft = centerX - r;
    const hexRight = centerX + r;
    const hexTop = centerY - r * Math.sqrt(3) / 2;
    const hexBottom = centerY + r * Math.sqrt(3) / 2;

    return !(hexRight < rectLeft || hexLeft > rectRight ||
             hexBottom < rectTop || hexTop > rectBottom);
}
```

#### 选择框绘制
- 填充：`rgba(74, 222, 128, 0.15)` 半透明绿色
- 边框：`rgba(74, 222, 128, 0.8)` 绿色虚线，线宽 2px
- 虚线样式：`[5, 5]`

### 3.6 网格向量化坐标系统

#### 状态变量
```javascript
coordEnabled: boolean         // 坐标是否显示
gridCoordinates: Array<{      // 网格坐标数据
    gridId: string,           // 网格唯一ID (row_col)
    row: number,              // 行索引
    col: number,              // 列索引
    x: number,                // x 坐标（原点在右下角）
    y: number,                // y 坐标（原点在右下角）
    centerXNatural: number,   // 自然坐标系下的中心 X
    centerYNatural: number,   // 自然坐标系下的中心 Y
    hexSizeNatural: number    // 自然坐标系下的六边形大小
}>
```

#### 坐标系设计
```
                    y 轴
                    ↑
                    |
                    |
         (0, W) ┌───┼───┐ (H, W)
                 │   │   │
                 │   │   │
         (0, 0) └───┼───┘ (H, 0)
                    |
         <──────────┼────────── x 轴
                    |
```

- **坐标系类型**：二维笛卡尔坐标系，第一象限
- **原点位置**：图片右下角顶点 (0, 0)
- **x 轴方向**：向左为正方向
- **y 轴方向**：向上为正方向
- **坐标单位**：像素（基于图片自然尺寸）
- **坐标定义**：网格中心的坐标即为该网格的坐标

#### 坐标计算公式
```javascript
// 图片自然尺寸
naturalWidth = previewImage.naturalWidth
naturalHeight = previewImage.naturalHeight

// 网格中心在自然坐标系中的位置（左上角为原点）
centerXNatural = (col * xDist + (row % 2 === 1 ? xDist / 2 : 0)) / imageScale
centerYNatural = (row * yDist) / imageScale

// 转换为右下角为原点的坐标系
x = naturalWidth - centerXNatural
y = naturalHeight - centerYNatural
```

#### 导出功能
- 导出格式：JSON
- 文件名：`grid-coordinates.json`
- 使用 Blob URL 方式下载

#### 导出 JSON 数据格式说明

导出的 JSON 文件是一个数组，每个元素代表一个网格的完整数据。

**JSON 结构示例：**
```json
[
  {
    "gridId": "0_0",
    "row": 0,
    "col": 0,
    "x": 1920,
    "y": 1080,
    "centerXNatural": 0,
    "centerYNatural": 0,
    "hexSizeNatural": 120
  }
]
```

**各字段详细说明：**

| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| `gridId` | string | 网格唯一标识符，格式为 `${row}_${col}` | `"0_0"`、`"2_3"` |
| `row` | number | 网格所在的行索引，从 -1 开始计数 | `0`、`1`、`-1` |
| `col` | number | 网格所在的列索引，从 -1 开始计数 | `0`、`2`、`-1` |
| `x` | number | 网格中心的 x 坐标（像素）<br>- 坐标系原点：图片右下角<br>- 正方向：向左<br>- 单位：基于图片自然尺寸 | `1920`、`960.5` |
| `y` | number | 网格中心的 y 坐标（像素）<br>- 坐标系原点：图片右下角<br>- 正方向：向上<br>- 单位：基于图片自然尺寸 | `1080`、`540.0` |
| `centerXNatural` | number | 网格中心在自然坐标系中的 x 坐标（像素）<br>- 坐标系原点：图片左上角<br>- 正方向：向右<br>- 单位：基于图片自然尺寸 | `0`、`207.846` |
| `centerYNatural` | number | 网格中心在自然坐标系中的 y 坐标（像素）<br>- 坐标系原点：图片左上角<br>- 正方向：向下<br>- 单位：基于图片自然尺寸 | `0`、`180.0` |
| `hexSizeNatural` | number | 六边形半径（中心到顶点的距离）<br>- 单位：基于图片自然尺寸 | `120` |

**坐标系统转换关系：**

```javascript
// 从自然坐标系（左上角为原点）转换为向量化坐标系（右下角为原点）
x = naturalWidth - centerXNatural;
y = naturalHeight - centerYNatural;

// 从向量化坐标系转换回自然坐标系
centerXNatural = naturalWidth - x;
centerYNatural = naturalHeight - y;
```

**使用说明：**
1. `x` 和 `y` 是主要的向量化坐标，用于定位网格
2. `row` 和 `col` 可用于网格的逻辑定位
3. `centerXNatural` 和 `centerYNatural` 可用于在原始图片上进行像素级操作
4. `hexSizeNatural` 可用于计算六边形的实际覆盖范围

### 3.7 网格颜色设置模块

#### 状态变量
```javascript
currentGridColor: string   // 当前选择的颜色，默认值: '#4ade80'
defaultGridColor: string   // 默认网格颜色，默认值: '#4ade80'
gridColorMap: Map<string, string>  // 网格ID到颜色的映射
```

#### 实现方式
- 使用 HTML5 `<input type="color">` 颜色选择器控件
- 默认颜色为绿色 `#4ade80`
- 每个网格可以有独立的颜色，使用 `gridColorMap` 保存
- 颜色变化逻辑：
  - **有选中网格时**：只改变选中网格的颜色，其他网格保持不变
  - **无选中网格时**：设置为默认颜色，新绘制的网格使用此颜色
- 网格绘制逻辑：
  - **有自定义颜色的网格**：一直保持填充状态，不管是否选中
  - **选中的网格**：在填充基础上再加粗边框
  - **无自定义颜色且未选中的网格**：只显示默认颜色边框
- 重置时清空颜色映射并恢复默认颜色

#### 颜色转换函数
```javascript
function hexToRgba(hex, alpha) {
    const r = parseInt(hex.slice(1, 3), 16);
    const g = parseInt(hex.slice(3, 5), 16);
    const b = parseInt(hex.slice(5, 7), 16);
    return `rgba(${r}, ${g}, ${b}, ${alpha})`;
}
```

#### 颜色选择器样式
- 尺寸：36px × 36px
- 边框：2px 实线，悬停时变为主题色
- 圆角：4px
- 内置颜色块无边框

## 4. 视觉设计

### 4.1 配色方案
```css
主背景: #1a1a1a          // 深灰色
次背景: #2a2a2a          // 稍深的灰色
主题色: #4ade80            // 绿色

```

### 4.2 布局设计
- **固定控制栏**: 使用 `position: fixed` 固定在顶部
- **全屏预览**: `position: fixed` 覆盖整个屏幕
- **图片容器**: 使用 flex 居中
- **相对定位**: 图片和网格使用父容器相对定位

### 4.3 交互反馈
- **按钮悬停**: 背景色或透明度变化
- **禁用状态**: 低透明度 + 禁用光标
- **拖拽光标**: `grab` (可拖拽) / `grabbing` (正在拖拽)
- **激活状态**: 按钮高亮 + 阴影效果

## 5. 性能优化

### 5.1 Canvas 优化
- 使用 `requestAnimationFrame` 理论优化（当前未实现）
- 只在网格激活时绘制
- Canvas 尺寸按需设置

### 5.2 CSS 性能
- 使用 `transform` �非 `width/height`（GPU 加速）
- 使用 `will-change: transform` 提示（可添加）
- 减少重排和重区

### 5.3 事件处理
- 事件监听器在 `document` 级上委托（mousemove, mouseup, keydown）
- 避免频繁的 DOM 查询（缓存 `querySelector` 结果）
