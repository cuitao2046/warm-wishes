# 本地图片查看器 - 设计文档

## 1. 系统架构

### 1.1 技术栈
- **HTML5**: 页面结构和语义化标签
- **CSS3**: 样式、变换、过渡动画
- **Vanilla JavaScript**: 无依赖的纯 JavaScript 实现
- **FileReader API**: 读取本地图片文件
- **Canvas API**: 绘制六边形网格

### 1.2 文件结构
```
image-viewer.html          # 单文件应用（包含所有 HTML、CSS、JavaScript）
```

## 3. 核心功能设计

### 3.1 图片上传模块

#### 数据流
```
用户操作 → fileInput change/drop
    → FileReader.readAsDataURL()
    → handleFiles()
    → loadedFiles.push(fileData)
    → showPreview(index)
```

#### 数据结构
```javascript
loadedFiles: Array<{
    name: string,        // 文件名
    size: number,        // 文件大小（字节）
    dataUrl: string      // Base64 编码的图片数据
}>

currentIndex: number          // 当前显示的图片索引
```

### 3.2 缩放模块

#### 状态变量
```javascript
currentZoom: number          // 当前缩放倍率 (0.1 ~ 10.0)
zoomStep: number = 0.25     // 缩放步长
minZoom: number = 0.1       // 最小缩放
maxZoom: number = 10.0      // 最大缩放
```

#### 实现方式
- 使用 CSS `transform: scale()` 实现缩放
- 使用 `transform-origin: 0 0` 设置缩放原点
- 添加 `transition: transform 0.1s ease-out` 平滑过渡
- 所有变换在同一 `applyTransform()` 函数中应用，确保图片和网格同步

### 3.3 拖拽模块

#### 状态变量
```javascript
isDragging: boolean          // 是否正在拖拽
startX: number              // 拖拽起始 X 坐标
startY: number              // 拖拽起始 Y 坐标
panX: number               // X 轴向偏移
panY: number               // Y 轴向偏移
```

#### 实现方式
- 事件：`mousedown` (imageWrapper), `mousemove` (document), `mouseup` (document)
- 只允许左键拖拽（`e.button === 0`）
- 只在缩放 > 1 时允许拖拽
- 使用 CSS `transform: translate()` 实现位移

### 3.4 六边形网格模块

#### 状态变量
```javascript
gridEnabled: boolean         // 网格是否显示
hexSize: number = 30       // 六边形半径（像素）
```

#### 实现方式
- 使用 `<canvas>` 元素作为覆盖层
- Canvas 尺寸使用图片的 `naturalWidth`/`naturalHeight`
- 六边形绘制逻辑：
  - 水平间距：`r * √3`
  - 垂直间距：`r * 1.5`
  - 奇数行向右偏移水平间距的一半
  - 六边形顶点角度从 `-π/6` 开始（30 度，尖顶朝上）

#### 为什么使用自然尺寸？
- 网格在原始图片分辨率上绘制
- CSS `transform` 统一应用于图片和网格
- 缩放和拖拽时两者完全同步，不会错位

### 3.5 导航模块

#### 状态变量
```javascript
currentIndex: number          // 当前图片索引
```

#### 导航逻辑
- 上一张：`currentIndex > 0` 时允许
- 下一张：`currentIndex < loadedFiles.length - 1` 时允许
- 切换图片时自动重置缩放和拖拽

## 4. 视觉设计

### 4.1 配色方案
```css
主背景: #1a1a1a          // 深灰色
次背景: #2a2a2a          // 稍深的灰色
主题色: #4ade80            // 绿色
文字色: #ffffff            // 白色
次级文字: #888888          // 浅灰色
边框色: #333333            // 深灰色边框
边框虚线: #444444          // 浅灰色虚线
```

### 4.2 布局设计
- **固定控制栏**: 使用 `position: fixed` 固定在顶部
- **全屏预览**: `position: fixed` 覆盖整个屏幕
- **图片容器**: 使用 flex 居中
- **相对定位**: 图片和网格使用父容器相对定位

### 4.3 交互反馈
- **按钮悬停**: 背景色或透明度变化
- **禁用状态**: 低透明度 + 禁用光标
- **拖拽光标**: `grab` (可拖拽) / `grabbing` (正在拖拽)
- **激活状态**: 按钮高亮 + 阴影效果

## 5. 性能优化

### 5.1 Canvas 优化
- 使用 `requestAnimationFrame` 理论优化（当前未实现）
- 只在网格激活时绘制
- Canvas 尺寸按需设置

### 5.2 CSS 性能
- 使用 `transform` �非 `width/height`（GPU 加速）
- 使用 `will-change: transform` 提示（可添加）
- 减少重排和重区

### 5.3 事件处理
- 事件监听器在 `document` 级上委托（mousemove, mouseup, keydown）
- 避免频繁的 DOM 查询（缓存 `querySelector` 结果）

|------|------|
| `←` / `→` | 上一张 / 下一张 |

| `0` | 重置缩放 |
| `G` / `g` | 切换网格 |

## 7. 扩状态管理

### 7.1 当前限制
- 不支持图片编辑（裁剪、滤镜等）
- 不支持图片保存
- 不支持图片旋转
- 不支持图片删除
- 不支持图片排序

### 7.2 未来扩展点
1. 支持 WebWorker 处理大图片
2. 支持图片导出
3. 支持图片元数据（EXIF）显示
4. 支持缩略图生成
5. 支持图片全屏模式
6. 支持多图平铺/网格浏览
7. 支持手势操作（移动端）
