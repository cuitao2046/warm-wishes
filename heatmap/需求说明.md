# 本地图片查看器 - 需求说明

## 1. 项目概述

本地图片查看器是一个基于 Web 的图片浏览工具，用于查看本地图片文件，并提供缩放、网格化等增强功能。

## 2. 功能需求

### 2.1 图片上传
- **FREQ-001**: 支持点击选择图片文件
- **FREQ-002**: 支持拖放上传图片文件
- **FREQ-003**: 支持多张图片同时上传
- **FREQ-004**: 支持常见图片格式（JPG、PNG、GIF、WEBP 等）
- **FREQ-005**: 非图片文件应给出提示

### 2.2 图片预览
- **FREQ-006**: 全屏预览图片
- **FREQ-007**: 自动适配图片尺寸（不超过屏幕 95% 宽度，保留控制栏空间）
- **FREQ-008**: 显示当前图片名称和文件大小
- **FREQ-009**: 图片圆角和阴影效果

### 2.3 导航功能
- **FREQ-010**: 上一张/下一张导航按钮
- **FREQ-011**: 显示当前序号和总数（如 "1 / 5"）
- **FREQ-012**: 第一张/最后张时禁用对应导航按钮
- **FREQ-013**: 键盘左右方向键导航
- **FREQ-014**: 切换图片时重置缩放和拖拽位置

### 2.4 缩放功能
- **FREQ-015**: 缩放增大按钮（+）
- **FREQ-016**: 缩放减小按钮（-）
- **FREQ-017**: 缩放重置按钮（1:1）
- **FREQ-018**: 显示当前缩放百分比（如 "100%"）
- **FREQ-019**: 缩放范围：10% ~ 1000%
- **FREQ-020**: 缩放步长：25%
- **FREQ-021**: 达到最大/最小缩放时禁用对应按钮
- **FREQ-022**: 键盘快捷键：+ 放大，- 缩小，0 重置
- **FREQ-023**: Ctrl/Command + 鼠标滚轮缩放

### 2.5 拖拽功能
- **FREQ-024**: 缩放超过 100% 时可拖拽移动图片
- **FREQ-025**: 仅允许左键拖拽
- **FREQ-026**: 拖拽时鼠标样式为 "grabbing"
- **FREQ-027**: 松开鼠标停止拖拽
- **FREQ-028**: 缩放回到 100% 或以下时重置拖拽位置

### 2.6 网格化功能
- **FREQ-029**: 六边形网格覆盖层
- **FREQ-030**: 网格显示/隐藏切换按钮
- **FREQ-031**: 激活状态下按钮高亮显示
- **FREQ-032**: 六边形半径：30px
- **FREQ-033**: 六边形样式：尖顶朝上，绿色半透明边框
- **FREQ-034**: 六边形无重叠、无空隙（蜂窝状排列）
- **FREQ-035**: 网格层使用图片自然尺寸绘制
- **FREQ-036**: 缩放/拖拽时网格层与图片同步变换
- **FREQ-037**: 键盘快捷键：G 切换网格显示

### 2.7 重置功能
- **FREQ-038**: 重置按钮清空所有图片
- **FREQ-039**: 返回上传界面
- **FREQ-040**: 关闭预览模式

### 2.8 添加更多图片
- **FREQ-041**: 在预览模式下可继续添加图片
- **FREQ-042**: 添加后显示新增图片

### 2.9 UI/UX 需求
- **FREQ-043**: 暗色主题背景
- **FREQ-044**: 控制栏固定在顶部
- **FREQ-045**: 控制栏半透明模糊背景
- **FREQ-046**: 按钮悬停效果
- **FREQ-047**: 拖拽区域悬停高亮效果
- **FREQ-048**: 响应式设计

## 3. 非功能需求

- **NFR-001**: 不支持图片编辑
- **NFR-002**: 不支持图片保存
- **NFR-003**: 不支持图片旋转
- **NFR-004**: 不支持图片删除
- **NFR-005**: 不支持图片排序

## 4. 性能需求

- **PERF-001**: 使用 FileReader API 读取本地文件
- **PERF-002**: 使用 Canvas 绘制网格（性能优化）
- **PERF-003**: 缩放使用 CSS transform（硬件加速）
- **PERF-004**: 缩放平滑过渡动画（100ms）

## 5. 兼容性需求

- **COMPAT-001**: 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- **COMPAT-002**: 不需要外部依赖
- **COMPAT-003**: 单文件部署（纯 HTML）
