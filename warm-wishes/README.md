# 为爱发电 - 传递温暖情感，找到同好伙伴

一个打破内向、传递爱与找到同好的温暖应用。

## 🎯 产品定位

### 名称
**为爱发电**

### 栓心理念
1. **情感表达** - 帮助中国人打破内向，勇敢表达爱意
2. **情绪赋能** - 带来热情、激情、多巴胺
3. **同好匹配** - 找到同方向、能互相赋能的人
4. **氛围营造** - 像 Party 一样有梦幻感

---

## 🎨 设计风格

### 关键词
**时尚 • 现代 • 简约 • 大气 • 有氛围感**

### 视觉元素
- **玻璃质感** - 透明背景、毛玻璃效果
- **灯泡效果** - 温暖、有层次、可交互
- **彩虹电波** - 动态、多彩、情绪化
- **透明泡泡** - 漂浮、梦幻、有生命力

### 情绪价值
- **热情** - 点燃内心
- **激情** - 充满能量
- **多巴胺** - 带来快乐
- **美好感受** - 温暖治愈

## 📁 项目结构

```
warm-wishes/
├── pages/              # 页面
│   ├── index/          # 首页（情绪中心）
│   └── friends/        # 亲友管理
├── components/         # 组件
│   ├── quote-card/     # 问候语卡片
│   ├── friend-card/    # 亲友卡片
│   ├── floating-bubbles/ # 漂浮泡泡
│   └── rainbow-wave/   # 彩虹电波
├── store/              # 状态管理
│   ├── quote.js       # 问候语 Store
│   ├── friend.js      # 亲友 Store
│   └── emotion.js     # 情绪 Store
├── static/             # 静态资源
├── manifest.json       # 应用配置
├── pages.json         # 页面配置
└── package.json       # 依赖配置
```

---

## 🛠️ 技术栈

- **框架**：uni-app (Vue 3)
- **状态管理**：Pinia
- **UI 设计**：玻璃质感 + 动画效果
- **存储**：本地存储（可升级为 uniCloud）
- **平台**：微信小程序

---

## 🧪 快速开始

### 1. 安装依赖

```bash
cd warm-wishes
npm install
```

### 2. 配置 AppID

编辑 `manifest.json`，填入你的微信小程序 AppID。

### 3. 运行项目

```bash
# HBuilderX（推荐）
导入项目 → 运行到小程序模拟器

# 或命令行
npm run dev:mp-weixin
```

## 📊 数据设计

### 情绪系统
```javascript
{
  energy: 50,              // 能量值（0-100）
  activeLevel: 0,          // 活跃度等级（0-5）
  dailyEmotions: [],       // 每日情绪记录（最近30天）
  totalReceived: 0,        // 总收到的问候数
  totalSent: 0            // 总发送的问候数
}
```

### 活跃度等级
- 萌新（0分）
- 初学者（20分）
- 活跃（40分）
- 达人（60分）
- 专家（80分）
- 大神（95分）
