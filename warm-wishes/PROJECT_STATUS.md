## 📝 配置说明

### 微信小程序配置
需要在 `manifest.json` 中配置：
- `mp-weixin.appid`：微信小程序 AppID
- API 权限：分享、存储等

### 环境变量
```bash
# 安装依赖
npm install

# 开发模式（微信小程序）
npm run dev:mp-weixin

# 构建生产版本
npm run build:mp-weixin
```
